# 📌 Суть задания

Посмотреть общую картину данных и провести базовый статистический анализ.

# 🧹 3. Предобработка данных (Data Preprocessing)

Нужно:

* удалить пропуски (missing data),
* убрать выбросы (outliers),
* удалить дубликаты.

---

# 📈 4. EDA (Exploratory Data Analysis)

Исследовать данные:

* по времени,
* по регионам,
* по клиентам,
* по товарам.

Найти интересные закономерности и необычные явления.

Например:

* какие товары популярны в каких странах,
* сезонность,
* кто покупает больше всего,
* какие клиенты приносят основной доход и т.д.

---

# 🤖 5. Prediction (предсказание)

## Classification

По информации о клиенте предсказать:

* купит он товар или нет (`Buy / Not Buy`).

## Regression

По товару, региону и другим данным предсказать:

* сколько будет продаж.

---

# ⚙️ Какие модели использовать

Обязательно применить:

* Random Forest Classifier
* Random Forest Regressor

То есть:

* классификация → RandomForestClassifier,
* прогноз чисел/продаж → RandomForestRegressor.
